# 距离相关系数矩阵计算函数技术说明

## —— `compute_dcor_matrix()` 方法学文档（供SCI论文学方法部分撰写参考）

---

## 一、方法学背景

### 1.1 距离相关系数概述

距离相关系数（Distance Correlation，dcor）由 Székely 等（2007）提出，是衡量两个随机变量之间依赖关系的非参数统计量。与传统的 Pearson 相关系数相比，距离相关系数具有以下关键优势：

| 特性 | Pearson 相关 | 距离相关 (dcor) |
|------|-------------|----------------|
| 线性关系检测 | ✓ | ✓ |
| 非线性关系检测 | ✗ | ✓ |
| 非单调关系检测 | ✗ | ✓ |
| 同分布为0时独立 | ✓（高斯情形） | ✓（一般情形） |
| 适用变量类型 | 仅连续变量 | 连续、分类均可 |
| 取值范围 | [-1, 1] | [0, 1] |

距离相关系数的核心性质：**当且仅当两个变量相互独立时，距离相关系数为 0**。这一性质是 Pearson 相关系数所不具备的（Pearson 相关系数为 0 仅表示不存在线性关系，不能排除非线性依赖关系的存在）。

### 1.2 数学定义

设 X 和 Y 分别为 p 维和 q 维随机变量，样本量为 n。距离相关系数的计算步骤如下：

**步骤 1：计算成对欧氏距离矩阵**

$$a_{ij} = \|X_i - X_j\|_p, \quad b_{ij} = \|Y_i - Y_j\|_q$$

其中 $X_i, X_j$ 为第 $i$ 和第 $j$ 个观测的 X 值。

**步骤 2：双重中心化（double-centering）**

$$A_{ij} = a_{ij} - \bar{a}_{i\cdot} - \bar{a}_{\cdot j} + \bar{a}_{\cdot\cdot}$$

$$B_{ij} = b_{ij} - \bar{b}_{i\cdot} - \bar{b}_{\cdot j} + \bar{b}_{\cdot\cdot}$$

其中 $\bar{a}_{i\cdot}$ 为第 $i$ 行均值，$\bar{a}_{\cdot j}$ 为第 $j$ 列均值，$\bar{a}_{\cdot\cdot}$ 为总均值。

**步骤 3：计算距离协方差与距离方差**

样本距离协方差：

$$\mathrm{dCov}^2(X, Y) = \frac{1}{n^2} \sum_{i=1}^{n} \sum_{j=1}^{n} A_{ij} B_{ij}$$

样本距离方差：

$$\mathrm{dVar}^2(X) = \frac{1}{n^2} \sum_{i=1}^{n} \sum_{j=1}^{n} A_{ij}^2$$

**步骤 4：计算距离相关系数**

$$\mathcal{R}(X, Y) = \frac{\mathrm{dCov}(X, Y)}{\sqrt{\mathrm{dVar}(X) \cdot \mathrm{dVar}(Y)}}$$

距离相关系数 $\mathcal{R}(X,Y) \in [0, 1]$，当且仅当 X 与 Y 独立时为 0，当 Y 为 X 的线性函数时为 1。

## 二、混合变量类型的编码策略（本函数核心方法学创新点）

### 2.1 问题提出

距离相关系数的原始定义基于欧氏距离，适用于连续变量。但医学科研数据中常包含多种变量类型，直接将分类变量编码为整数（如 1/2/3）会引入虚假的"序"信息，扭曲无序分类变量之间的距离关系。因此，**针对不同变量类型采用差异化编码策略**是保证距离相关系数正确性的关键。

### 2.2 本函数采用的编码策略

#### 2.2.1 连续变量

直接使用原始数值，无需任何转换。第 $i$ 与第 $j$ 个观测之间的距离为：

$$d(x_i, x_j) = |x_i - x_j|$$

#### 2.2.2 二分类变量（无论有序还是无序）

采用 0/1 编码。对于二分类变量，0/1 编码无论名义还是有序变量均产生相同的距离结构：

$$d(x_i, x_j) = |x_i - x_j| = \begin{cases} 0, & \text{同一类别} \\ 1, & \text{不同类别} \end{cases}$$

这等价于**匹配距离**（matching distance），是分类变量最自然的距离度量。由于二分类变量只有两个水平，有序性与无序性在距离结构上是等价的，因此 0/1 编码对两者均适用。

#### 2.2.3 三分类（及以上）无序分类变量

采用**独热编码**（one-hot encoding / dummy variable encoding）。将 K 分类变量转换为 K 个二值指示变量。以三分类为例：

| 原始类别 | 编码向量 |
|---------|---------|
| A | (1, 0, 0) |
| B | (0, 1, 0) |
| C | (0, 0, 1) |

独热编码后计算欧氏距离，任意两个不同类别之间的距离均为 $\sqrt{2}$：

$$d(\text{A}, \text{B}) = \sqrt{(1-0)^2 + (0-1)^2 + (0-0)^2} = \sqrt{2}$$

$$d(\text{A}, \text{C}) = \sqrt{(1-0)^2 + (0-0)^2 + (0-1)^2} = \sqrt{2}$$

$$d(\text{B}, \text{C}) = \sqrt{(0-0)^2 + (1-0)^2 + (0-1)^2} = \sqrt{2}$$

**方法学依据**：独热编码确保所有类别对之间的距离相等，即类别之间不存在"远近"关系，忠实反映了无序分类变量的本质特征。这与简单整数编码（1/2/3，会引入 A-B 距离为 1 而 A-C 距离为 2 的虚假序结构）形成对比。

#### 2.2.4 三分类（及以上）有序分类变量

采用**整数编码**（integer/rank encoding），按类别等级依次赋值 1, 2, 3, ..., K。

以三分类有序变量为例（如肿瘤分期 I/II/III）：

| 原始类别 | 编码值 | 相互距离 |
|---------|-------|---------|
| I | 1 | d(I, II) = 1 |
| II | 2 | d(II, III) = 1 |
| III | 3 | d(I, III) = 2 |

**方法学依据**：整数编码产生的距离矩阵保留了序结构——相邻类别（如 I 期与 II 期）之间的距离小于非相邻类别（如 I 期与 III 期），符合有序分类变量"程度递进"的本质。此外，距离相关系数对编码的线性变换具有不变性（将所有编码值同乘常数不改变 dcor 值），因此编码起点（从 0 或 1 开始）不影响结果。

### 2.3 编码策略汇总表

| 变量类型 | 编码方法 | 观测间距离 | 方法学依据 |
|---------|---------|-----------|-----------|
| 连续变量 | 原始数值 | $\|x_i - x_j\|$（欧氏距离） | 连续变量的自然距离度量 |
| 二分类（有序/无序） | 0/1 编码 | 匹配距离（0 或 1） | 二分类下有序与无序等价 |
| ≥3 分类无序 | 独热编码 | 任意不同类别间距离恒为 $\sqrt{2}$ | 消除虚假序结构，类别等距 |
| ≥3 分类有序 | 整数编码 | $\|\text{rank}_i - \text{rank}_j\|$ | 保留序信息，相邻类别更近 |

## 三、缺失值处理

### 3.1 策略：成对删除（Pairwise Deletion）

本函数采用成对删除策略处理缺失值：对于每一对变量 (X, Y)，仅保留 X 与 Y 均无缺失的观测值进行距离相关系数计算。即：

$$\text{有效样本} = \{(x_i, y_i) : x_i \neq \text{NA} \text{ 且 } y_i \neq \text{NA}\}$$

### 3.2 方法学依据与适用条件

**优点**：
- 每对变量均最大化利用可用数据，避免因单个变量缺失而删除整行（行删除法/listwise deletion）造成的信息损失；
- 在缺失比例较低（如 < 5%）且缺失机制为完全随机缺失（MCAR）时，成对删除的估计偏倚可忽略。

**注意事项**：
- 不同变量对的距离相关系数可能基于不同的有效样本量，在解释比较时需注意；
- 若缺失比例较高或缺失机制非随机（MNAR），建议在论文方法学部分说明，并考虑敏感性分析。

**论文中可表述为**：
> "缺失数据采用成对删除法（pairwise deletion）处理，即每对变量的距离相关系数基于两者均无缺失的观测值计算。本研究各变量缺失比例均较低（<X%），对结果的影响可忽略。"

### 3.3 最小样本量要求

函数设定每对变量的有效样本量不得少于 5 例（n ≥ 5），否则跳过该对计算并返回 NA。这是距离相关系数计算与置换检验的最低要求。

## 四、统计推断：置换检验

### 4.1 检验假设

$$H_0: X \text{ 与 } Y \text{ 相互独立} \quad \text{vs.} \quad H_1: X \text{ 与 } Y \text{ 不独立}$$

### 4.2 置换检验原理

在 $H_0$（独立）成立的前提下，X 与 Y 的配对关系可以任意交换。置换检验的步骤如下：

1. **计算观测统计量**：基于原始配对数据计算距离相关系数 $\mathcal{R}_{\text{obs}}$；
2. **置换重抽样**：将 Y 的观测值随机打乱（等价于随机重排 X 与 Y 的配对关系），基于打乱后的数据重新计算距离相关系数 $\mathcal{R}^{(b)}$，重复 B 次（本函数 B = R = 1000）；
3. **计算 P 值**：

$$p = \frac{1 + \sum_{b=1}^{B} \mathbb{I}(\mathcal{R}^{(b)} \geq \mathcal{R}_{\text{obs}})}{B + 1}$$

其中 $\mathbb{I}(\cdot)$ 为指示函数。分母中的 "+1" 是将观测统计量本身计入，避免 P 值为 0，保证检验的有效性（validity）。

### 4.3 为什么选择置换检验而非渐近检验

| 方法 | 优势 | 局限 |
|------|------|------|
| 渐近检验（如 t 检验近似） | 计算快 | 依赖大样本渐近性质，小样本时可能不准 |
| **置换检验** | 任意样本量下均有效；对分布无假设；精确性可控 | 计算量大（需 B 次重计算） |

置换检验是一种**非参数精确检验**（exact test），其有效性不依赖任何分布假设，在小到中等样本量（医学科研常见情形）下表现稳健。B = 1000 次置换可提供足够的 P 值精度（最小非零 P 值为 1/1001 ≈ 0.001）。

### 4.4 实现细节

本函数调用 `energy` 包（Rizzo & Székely, 2024）中的 `dcor.test()` 函数执行置换检验。若该函数不可用（旧版 energy 包），自动回退至 `dcov.test()`（该函数返回的 `estimates` 向量中包含 dcor 值及相同的置换 P 值）。

**多重共线性优化**：利用距离相关系数的对称性（$\mathcal{R}(X,Y) = \mathcal{R}(Y,X)$，且置换检验 P 值亦对称），函数仅计算上三角矩阵后镜像填充，将计算量减半。

## 五、显著性标记

根据置换检验 P 值，按以下标准标注统计学显著性：

| P 值范围 | 标记 | 含义 |
|---------|------|------|
| P < 0.001 | *** | 高度显著 |
| 0.001 ≤ P < 0.01 | ** | 非常显著 |
| 0.01 ≤ P < 0.05 | * | 显著 |
| P ≥ 0.05 | ns | 不显著 |
| 不可计算 | - | 对角线（自相关）或计算失败 |

## 六、软件实现

### 6.1 运行环境

- **编程语言**：R（≥ 4.0.0 推荐）
- **核心依赖包**：`energy`（Rizzo & Székely 开发，CRAN 提供）
- **安装命令**：`install.packages("energy")`

### 6.2 函数调用

```r
# 基本用法（自动检测变量类型）
result <- compute_dcor_matrix(data, R = 1000)

# 手动指定变量类型（推荐，确保分类变量的有序/无序属性正确识别）
result <- compute_dcor_matrix(
  data,
  var_types = c(
    age       = "continuous",       # 连续变量
    sex       = "binary_nominal",   # 二分类无序
    hyper     = "binary_ordinal",   # 二分类有序
    blood_type = "ternary_nominal", # 三分类无序
    stage     = "ternary_ordinal"   # 三分类有序
  ),
  R = 1000
)
```

### 6.3 输出格式

返回长格式（long-format）数据框，包含 5 列：

| 列名 | 含义 |
|------|------|
| Column Variable | 列变量名 |
| Row Variable | 行变量名 |
| Distance Correlation | 距离相关系数（0~1） |
| P Value | 置换检验 P 值 |
| Significance | 显著性标记（*** / ** / * / ns / -） |

对于 p 个变量，输出共 $p^2$ 行（含对角线）或 $p^2 - p$ 行（不含对角线，通过 `include_diag = FALSE` 设置）。对角线元素的距离相关系数为 1（变量与自身的距离相关恒为 1），P 值和显著性标记为 "-"。

## 九、方法学局限性说明（供 Discussion 部分参考）

在论文讨论部分，可考虑提及以下方法学局限：

1. **多重比较问题**：对 p 个变量进行 $p(p-1)/2$ 次两两检验时，多重比较会增大整体 I 类错误率。若研究目的为探索性分析，可不做校正；若需严格推断，建议报告 Bonferroni 校正或 Benjamini-Hochberg 错误发现率（FDR）控制后的结果。

2. **距离相关系数的取值解释**：dcor 取值范围为 [0, 1]，但其数值大小与关联强度的对应关系不如 Pearson 相关直观（dcor = 0.3 与 Pearson r = 0.3 的关联强度不同），在结果解释时应予以注意。

3. **编码策略的影响**：对于无序分类变量，独热编码的假设是所有类别"等距"；若实际类别间存在某种结构性距离（如某些类别更相似），该假设可能不完全成立。可根据研究背景选择更合适的距离度量。

4. **有效样本量不一致**：成对删除法导致不同变量对的检验样本量不同，在进行跨变量对的比较时需注意。
